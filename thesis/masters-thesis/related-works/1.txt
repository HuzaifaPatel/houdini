Problem Statement: Containers lack strong isolation compared to virtual machines (VMs).

LiCShield is a framework that:

	Automatically traces container behavior in a test environment.

	Generates AppArmor profiles for both the host and the container workloads.

	Aims to block any activity not observed during pre-production testing.

Creates Apparmor profiles based on dynamic execution of containers

Rather than statically blocking unknown behavior, we can use Houdini to validate whether containers can escape or escalate privileges in real-world scenarios. This gives practical assurance that restrictions work.
