Attacks are Forwarded: Breaking the Isolation of MicroVM-based Containers Through Operation Forwarding

MicroVM-based containers (e.g., Firecracker, Kata Containers) are designed to increase security by adding virtualization.

These containers combine the security of VMs with the performance of containers. kind of like houdini

This paper reveals a new class of attacks called operation forwarding attacks that break the assumed strong isolation of microVM-based containers (like Firecracker and Kata Containers).

Authors analyze microVM container architecture in 3 layers:

	Container runtime components (virtiofsd, firecracker-containerd)

	Device emulator (QEMU, Firecracker)

	Host kernel components (KVM, vhost-net)

Designed two attack strategies:

	Exploit container runtime to issue privileged host syscalls.

	Trigger device emulators to exhaust host resources
