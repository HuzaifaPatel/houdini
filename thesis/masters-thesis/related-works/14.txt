Lic-Sec: An enhanced AppArmor Docker security profile generator



Docker-sec and LiCShield generate AppArmor profiles to secure containers, but Docker-sec lacks some file access rules; LiCShield is incompatible with recent Docker versions.

PURPOSE

To design and implement a new AppArmor profile generator called Lic-Sec that combines the strengths of both tools.
it is a dynamic analyzer.

IMEPLEMENTATION

Uses SystemTap and Auditd for tracing

EVALUATION

Lic-Sec successfully defended all privilege escalation and container escape attacks that Docker-sec and LiCShield failed to block.
