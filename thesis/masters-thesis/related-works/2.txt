Highlights Denial of Service (DoS) attacks as a major threat.

Proposes practical methods to mitigate DoS risks in Docker environments.

they argue that cgroups help limit CPU, memory, I/O, essential against DoS, but don’t isolate containers fully.

they proposed DoS Mitigation technique:

	Test Case 1: Limit memory using -m=512mb in docker run (Prevents containers from consuming all host memory)

	Test Case 2: Use default memory limit in /etc/default/docker.

	Test Case 3: Apply a system-wide container limit when no memory limit is set.
